 核心思路：让压缩不再依赖 LLM 生成摘要，而是直接从持久化的 session memory 文件中读取笔记，作为压缩后的上下文重建。这样既省了一次 LLM 调用，又保留了更丰富的上下文。

  关键设计决策：
  - 不引入 LLM 驱动提取（保持正则提取，低成本）
  - 不引入远程配置（静态配置 + 环境变量覆盖）
  - Session memory 替代而非补充 LLM 摘要
  - 向后兼容，默认开启

   实施总结

  1.1 边界跟踪 (sessionMemory.ts):
  - 新增模块级状态 lastSummarizedMessageId: string | undefined
  - getLastSummarizedMessageId() / setLastSummarizedMessageId() / resetSummarizedMessageId()
  - persistSessionMemoryWithTokenCount() 写入元数据行 LastSummarizedMessageId: <uuid>
  - parseSessionMemoryMarkdown() 解析元数据，readSessionMemory() 自动恢复状态
  - initSession() 重建时自动从磁盘恢复 lastSummarizedMessageId

  1.2 并发提取防护:
  - extractionStartedAt: number | undefined + stale detection（60 秒）
  - markExtractionStarted() / markExtractionCompleted()
  - waitForSessionMemoryExtraction(timeoutMs) — 轮询等待，15 秒超时
  - endSession() 清理所有提取状态

  1.3 节截断 + 空检查:
  - isSessionMemoryEmpty(content) — 检查是否只有模板没有实际笔记
  - truncateSessionMemoryForCompact(content, maxTotalTokens) — 按段截断：
    - 每段上限 2000 tokens
    - 总上限 12000 tokens（可配置）
    - 智能在完整列表项处断行，保留 section header
