  核心设计决策

  - 不引入 React/Ink — mailboxPoller 用纯 async 轮询替代 useInboxPoller hook，保持 mini-v8 无 UI 架构
  - ALS 而非 Map — 用 Node.js AsyncLocalStorage 解决并发 agent 上下文冲突（Bun 完整支持）
  - 通知队列用模块级数组 — 非 React state，CLI 流循环可直接 drain，无需引入 Zustand
  - 保留同步 API — runAgentSync 保持现有行为不变，runAgentAsync 是新增能力

  核心能力

  - runAgentSync() — 阻塞等待，行为与改前完全一致
  - runAgentAsync() — 立即返回 AgentTaskState，后台执行，通过 agentTaskStore 追踪进度
  - AbortController 隔离 — 异步 agent 拥有独立的 AbortController，父级取消不影响后台任务
  - agentTaskStore — 完整的生命周期管理：running → completed/failed/killed，支持进度更新和批量 kill
