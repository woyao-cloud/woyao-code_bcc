 mini-v8 当前有 37 个内置工具，全部在初始化时完整加载到 API 请求中。完整版项目使用"延迟工具"机制：核心工具（~20 个）始终加载完整 schema，其余工具按需通过 SearchExtraTools
      发现、ExecuteExtraTool 代理执行，从而节省 context window token。

     本次任务将这 3 个工具及其依赖的 TF-IDF 搜索引擎移植到 mini-v8。

     新增文件（10 个）

     1. mini-v8/src/services/searchExtraTools/localSearch.ts

     TF-IDF 共享引擎，从完整版 src/services/skillSearch/localSearch.ts 移植。核心函数：

     ┌───────────────────────────┬───────────────────────────────────────────────────────────────┐
     │           函数            │                             职责                              │
     ├───────────────────────────┼───────────────────────────────────────────────────────────────┤
     │ tokenize(text)            │ 分词：英文按单词边界（120+ 停用词），中文留空待扩展           │
     ├───────────────────────────┼───────────────────────────────────────────────────────────────┤
     │ stem(word)                │ 简单词干提取：去 ing/tion/ness/ment/ers/er/es/s/ed/ly 后缀    │
     ├───────────────────────────┼───────────────────────────────────────────────────────────────┤
     │ tokenizeAndStem(text)     │ 组合分词+词干                                                 │
     ├───────────────────────────┼───────────────────────────────────────────────────────────────┤
     │ computeWeightedTf(fields) │ 加权词频：每字段 (freq/maxFreq) * fieldWeight，取各字段最大值 │
     ├───────────────────────────┼───────────────────────────────────────────────────────────────┤
     │ computeIdf(index)         │ 逆文档频率：log(N/df)                                         │
     ├───────────────────────────┼───────────────────────────────────────────────────────────────┤
     │ cosineSimilarity(a, b)    │ 余弦相似度                                                    │
     └───────────────────────────┴───────────────────────────────────────────────────────────────┘
