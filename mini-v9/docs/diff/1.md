## 3. 工具类缺失总结

### MCP 相关 (3个)
- `ListMcpResourcesTool` — 列出 MCP 资源
- `McpAuthTool` — MCP OAuth 认证
- `ReadMcpResourceTool` — 读取 MCP 资源  
- **影响**: MCP 资源读写能力受限

### Git/Worktree (2个)
- `EnterWorktreeTool` — 进入 Git worktree
- `ExitWorktreeTool` — 退出 Git worktree
- **影响**: 无 worktree 隔离能力

### GitHub/PR (2个)
- `SubscribePRTool` — 订阅 PR 变更
- `SuggestBackgroundPRTool` — 建议后台 PR
- **影响**: 无 GitHub PR 集成

### REPL/终端 (2个)
- `REPLTool` — REPL 环境交互
- `TerminalCaptureTool` — 终端捕获
- **影响**: 无 REPL 和终端捕获

### 通知/推送 (1个)
- `PushNotificationTool` — 桌面推送通知
- **影响**: 无桌面推送

### 远程 (1个)
- `RemoteTriggerTool` — 远程触发
- **影响**: 无远程控制

### 其他 (4个)
- `DiscoverSkillsTool` — 技能发现
- `OverflowTestTool` — 溢出测试
- `ReviewArtifactTool` — 评审产物
- `ScheduleCronTool` — 定时任务 (mini-v9 有独立的 CronCreate/Delete/List)
- `SnipTool` — 截断
- `TungstenTool` — Tungsten 集成
- `VaultHttpFetchTool` — Vault HTTP 获取

## 5. 保留的核心能力

Mini-v9 **保留了**以下核心能力:

- ✅ **Agent 系统** (12 文件) — AgentRegistry, AgentRunner, builtInAgents, agentMemory, forkSubagent, summarization, mailbox, teamManager
- ✅ **工具系统** (47 个工具) — 覆盖完整版 75% 的工具
- ✅ **Query Engine** — query.ts + QueryEngine.ts + transitions.ts
- ✅ **Context 构建** — context.ts (1186 行, 比完整版更丰富)
- ✅ **API 层** — Claude + OpenAI + Gemini 兼容
- ✅ **压缩系统** (11 文件) — 含 stagedCompact 独有特性
- ✅ **权限管理** (4 文件) — 集中式实现
- ✅ **内存系统** (7+ 文件) — 含 mini-v9 独有的 memoryAge/findRelevantMemories
- ✅ **Skill 系统** — skillLoader + skillStore + mcpSkillBuilders
- ✅ **Plan Mode** — planMode.ts + planModeV2.ts + planStore.ts
- ✅ **会话存储** — sessionStore.ts
- ✅ **纯终端 UI** (9 文件) — spinner, statusBar, renderer, input, dialogs
- ✅ **Cron** — scheduler.ts + CronCreate/Delete/List 工具
- ✅ **Workflow** — WorkflowTool + workflowStore (独有!)
- ✅ **Git 工具** — GitDiff/GitLog/GitStatus (独有!)

## 8. 升级到完整版兼容性的建议

如果要将 mini-v9 与完整版对齐，建议按以下顺序:

### 第一阶段 — API 兼容 (~2周)
- 对齐 Tool 接口类型
- 对齐 Message 类型
- 对齐 API 请求/响应格式

### 第二阶段 — 功能补齐 (~1月)
- 移植 Bridge 核心 (bridgeMain.ts)
- 移植 OAuth 流程
- 移植 Plugin 系统
- 移植 Skill 系统

### 第三阶段 — 场景增强 (~1月)
- 移植 SSH/Voice/Vim
- 移植 Swarm 多后端
- 移植 Daemon 模式
- 移植 Computer Use

### 第四阶段 — 体验优化 (持续)
- 移植 Provider 注册表
- 移植遥测 (可选)
- 移植 Keyboard bindings (可选)
