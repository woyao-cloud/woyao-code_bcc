# 前言与导读

## 关于本书

本书是一份关于 Claude Code CLI 项目（mini-v9 分支）的技术架构解析文档。Claude Code 是 Anthropic 官方推出的 AI 编程助手 CLI 工具，mini-v9 是其一个经逆向工程恢复并精简后的分支版本，保留了核心的 Agent 循环、工具系统、Context 管理、多 Agent 协作等关键架构。

本书的目标读者是希望深入理解 AI 编程助手内部工作机制的中高级开发者。全文采用自然语言描述，不涉及具体代码实现细节，最多到类/模块级别，帮助读者建立宏观架构认知。

## 项目整体鸟瞰

从宏观上看，mini-v9 项目是一个运行在终端中的 **Agent 驱动型 AI 编程助手**。用户通过命令行输入自然语言指令，系统将其发送到 LLM（大语言模型），模型返回文本或工具调用请求，系统执行工具（如读取文件、搜索代码、运行命令）并将结果返回给模型，如此循环，直到任务完成。

整个系统可以分解为以下几个核心子系统：

```
┌─────────────────────────────────────────────────────┐
│                    终端 UI (Ink)                     │
│              REPL 屏幕 / 消息渲染 / 权限提示          │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│              Agent 核心运行循环 (QueryEngine)        │
│   消息构建 → API 通信 → 工具调度 → 结果收集 → 下一轮  │
└──────────────────────┬──────────────────────────────┘
                       │
          ┌────────────┼────────────┬──────────────┐
          ▼            ▼            ▼              ▼
   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────┐
   │Context   │ │Memory    │ │Tool 系统 │ │多 Agent 协作  │
   │管理      │ │体系      │ │60+ 工具  │ │AgentTool/Teammate
   └──────────┘ └──────────┘ └──────────┘ └──────────────┘
```

## 章节路线图

本书共分 8 章，建议按顺序阅读：

- **第 1 章：项目概览与架构总览** — 整体架构、技术栈、目录结构、构建体系
- **第 2 章：Agent 核心运行循环** — Agent 循环的完整设计：消息准备、System Prompt 动态组装、流式 API 通信、工具并发调度、结果收集与异常兜底
- **第 3 章：多层 Context 管理机制** — 在 C 端长对话场景中保障体验不降级的设计
- **第 4 章：Memory 体系与个性化配置** — 跨会话持久化记忆、自动提取与离线巩固、Hooks 系统和项目级指令注入
- **第 5 章：Agent 埋点与可观测性** — 埋点规范、日志体系、事件追踪框架
- **第 6 章：C 端体验关键指标优化** — 首 token 延迟、流式输出流畅度、工具失败降级策略、静默失败检测与兜底
- **第 7 章：多 Agent 协作架构** — Fork 子 Agent、AgentTool 嵌套、并发子任务、团队协作
- **第 8 章：全链路流程追踪** — 从用户输入到最终输出的完整通路
