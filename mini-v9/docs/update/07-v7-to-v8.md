# mini-v7 → mini-v8 升级分析

## 版本信息

| 维度 | mini-v7 | mini-v8 |
|------|---------|---------|
| 版本号 | 7.0.0 | 8.0.0 |
| 描述 | Memory system | Multi-Agent Coordination: AgentTool, Teams, Coordinator, Swarm |
| 文件数 | 124 | 305 (+146%) |
| 测试数 | 22 | 40 (+82%) |
| 源代码目录 | 7 个 src/ 子目录 | 15 个 src/ 子目录 |

**这是整个系列中最大的一次升级**，文件数翻了一倍多，架构复杂度大幅提升。

---

## 新增功能总览

### 1. Agent 系统（全新模块 `src/agents/`）

v8 的核心创新——多 Agent 协作架构：

| 文件 | 说明 |
|------|------|
| `agentTypes.ts` | 完整类型定义：AgentDefinition, AgentInstance, TeamDefinition, TeamMember, AgentRunContext, AgentResult |
| `builtInAgents.ts` | **6 个内置 Agent**：Explore（只读搜索）、Plan（只读规划）、General-Purpose（全工具）、Verify（代码审查）、Coordinator（委派协调）、Worker（执行器） |
| `agentRegistry.ts` | Agent 注册中心，自动发现 built-in / `~/.claude/agents/` / `.claude/agents/` / 插件来源 |
| `agentRunner.ts` | 进程内子 Agent 执行引擎，支持工具过滤、轮次限制、结果聚合 |
| `agentMemory.ts` | **新增** — Agent 级别记忆，子 Agent 运行时上下文保持 |
| `agentMemorySnapshot.ts` | **新增** — 记忆快照，用于状态保存和恢复 |
| `mailboxPoller.ts` | **新增** — Agent 间消息轮询器 |
| `teammateMailbox.ts` | **新增** — Teammate 邮箱通信 |
| `index.ts` | 公开 API 导出 |

| Agent | 角色 | 工具列表 | 只读 |

## 升级要点总结

**v8 是整个系列最大的一次架构飞跃**，主题是"多 Agent 协作与平台化"：

1. **Agent 系统** — 6 个内置 Agent + 注册发现 + 执行引擎 + 记忆 + 邮箱通信
2. **团队管理** — 角色的创建/解散/成员管理/持久化
3. **Swarm 协调** — Coordinator 代理工作委派，并行子任务
4. **工具生态 44 个** — 从 15 个工具爆发式增长到 44 个（+193%）
5. **命令系统 19 个** — 从 3 个扩展到 19 个命令文件
6. **压缩系统** — 从单文件扩展到 10 个文件的多策略压缩
7. **新服务** — LSP、Cron、Session、SearchExtraTools、Tool Orchestration
8. **Gemini 兼容** — 继 OpenAI 之后的第二个第三方 API 兼容层
9. **QueryEngine** — 高层的 Agent 对话循环编排器
10. **测试覆盖** — 从 22 个测试增长到 40 个

**注意**：README.md 提到 v8 增强了 git.ts（远程 URL、工作区状态、文件信息、提交差距检测等），并新增了 git.test.ts。
