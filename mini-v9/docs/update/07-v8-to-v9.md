# mini-v8 → mini-v9 升级分析

## 版本信息

| 维度 | mini-v8 | mini-v9 |
|------|---------|---------|
| 版本号 | 8.0.0 | 8.0.0（同版本号） |
| 描述 | Multi-Agent Coordination | 同 v8（未更新描述） |
| 文件数 | 305 | 311 (+6) |
| 测试数 | 40 | 45 (+5) |
| 源代码目录 | 15 个 src/ 子目录 | 16 个 src/ 子目录（+ui/） |

> 注意：v9 的 package.json 版本号仍为 8.0.0，说明这是一个**功能增补版本**而非主版本变更。但从变更量级看，实际改动非常大。

## 新增功能总览

### 1. UI 层（全新模块 `src/ui/`）

**这是 v9 最大的架构性新增**。从 v8 的纯 CLI 交互升级为带有完整 UI 层的架构：

| 文件 | 说明 |
|------|------|
| `renderer.ts` | 终端渲染器 |
| `session.ts` | UI 会话管理 |
| `input.ts` | 用户输入处理 |
| `events.ts` | UI 事件系统 |
| `format.ts` | 格式化工具 |
| `state.ts` | UI 状态管理 |
| `statusBar.ts` | 状态栏组件 |
| `spinner.ts` | 加载动画 |
| `dialogs/types.ts` | 对话框类型定义 |
| `dialogs/permissionDialog.ts` | 权限授权对话框 |


### 2. Workflow 系统（全新）

| 新增项 | 说明 |
|--------|------|
| `WorkflowTool/WorkflowTool.ts` | Workflow 定义和执行工具 |
| `WorkflowTool/types.ts` | Workflow 类型定义 |
| `services/workflowStore.ts` | Workflow 持久化存储 |

Workflow 系统允许：
- 预定义多步工作流
- 跨多个 Agent 协调执行
- 工作流模板化复用

### 3. Fork Subagent（全新）

- **`agents/forkSubagent.ts`** — Fork 子 Agent 机制
- 支持从主会话 Fork 出一个独立子 Agent 执行任务
- 子 Agent 拥有自己的上下文和工具集，执行完成后返回结果
- 测试文件：`forkSubagent.test.ts`

### 4. Agent Summarization（全新）

- **`agents/agentSummarization.ts`** — Agent 摘要生成
- 自动总结子 Agent 的执行过程，生成摘要用于主上下文
- 减少子 Agent 运行时产生的上下文膨胀
- 测试文件：`agentSummarization.test.ts`

### 5. 新增 7 个工具（44→51）

| 工具 | 类别 | 说明 |
|------|------|------|
| **WorkflowTool** | 工作流 | 定义和执行多步工作流 |
| **CtxInspectTool** | 调试 | 上下文检查工具，查看当前系统提示/消息/工具状态 |
| **GitDiffTool** | Git | 查看 git diff |
| **GitLogTool** | Git | 查看 git log 历史 |
| **GitStatusTool** | Git | 查看 git status |
| **LocalMemoryRecallTool** | 记忆 | 本地记忆召回工具 |
| **MonitorTool** | 监控 | 后台监控文件/日志变更 |

### 6. Plan Mode V2

| 新增项 | 说明 |
|--------|------|
| `planModeV2.ts` | 第二代规划模式，增强的计划管理 |
| `planStore.ts` | 计划持久化存储 |

相比 v4 引入的 Plan Mode，v2 版本增加了：
- 计划存储和恢复
- 多计划管理
- 计划执行状态追踪

### 7. 压缩系统增强：Staged Compact

- **`compact/stagedCompact.ts`** — 阶段式上下文压缩
- 这是对话压缩的重要增强：
  - 非破坏性压缩：保留关键上下文
  - 按阶段渐进压缩：从老消息到新消息
  - 结合 sessionMemoryCompact 做完整上下文管理
- 对应 docs-plan: `8.2.1阶段式折叠.md`

### 8. Token Budget（全新）

| 新增项 | 说明 |
|--------|------|
| `query/tokenBudget.ts` | Query 层 token 预算管理 |
| `utils/tokenBudget.ts` | 工具函数层 token 预算 |

Token 预算系统用于：
- 控制每次 API 调用的 token 消耗上限
- 在长对话中智能分配 token 空间
- 防止超出模型上下文窗口

## 升级要点总结

**v9 的主题是"UI 层、工作流系统与内部增强"**：

1. **UI 层** — 最显著的架构新增，从纯 CLI 升级为带 UI 渲染层（spinner、statusBar、dialogs、renderer）
2. **Workflow 系统** — 全新的多步工作流引擎，WorkflowTool + workflowStore
3. **Fork Subagent** — 子 Agent Fork 机制，完善多 Agent 架构
4. **Git 三工具** — GitDiffTool + GitLogTool + GitStatusTool，Git 能力完整化
5. **Plan Mode V2** — 二代规划模式 + 计划存储
6. **Staged Compact** — 阶段式上下文压缩，缓解长对话 token 问题
7. **Token Budget** — 精细化的 token 预算管理
8. **Monitor Tool** — 后台文件/日志监控能力
9. **CtxInspect Tool** — 调试辅助工具
10. **LocalMemoryRecall** — 本地记忆召回
11. **测试覆盖** — 从 40 增长到 45 个测试文件
12. **文档体系** — 8 章中文架构书籍，docs-plan 30+ 个计划文档

**v9 没有改变的核心架构**：Agent 系统、命令系统、权限管理、MCP 支持、Plugin/Skill 生态、Memory 体系的核心结构保持不变。
