## 新增功能

### 1. MCP 协议支持（全新）
- **`src/services/mcp/mcpClient.ts`** — MCP (Model Context Protocol) 客户端
- 支持通过 MCP 协议连接外部工具/数据源，大幅扩展模型的工具生态
- 这是与 Anthropic MCP 生态对接的关键基础设施

### 2. Config 管理器（全新）
- **`src/services/config/configManager.ts`** — 配置管理器
- 结构化的配置读写，替代之前零散的配置处理
- 为后续的 /config 命令打下基础

### 3. Auto-Compact（全新）
- **`src/services/compact/autoCompact.ts`** — 自动上下文压缩
- 当对话历史过长时自动压缩，减少 token 消耗
- 这是长会话管理的首个基础设施

### 4. Retry 机制（全新）
- **`src/services/retry.ts`** — API 重试服务
- 自动重试失败的 API 调用，提高鲁棒性

### 5. 新增 1 个工具（14→15）
| 新增工具 | 说明 |
|----------|------|
| MCPTool | MCP 工具调用，连接外部 MCP 服务器获取扩展能力 |

### 6. 新增依赖
- 首次引入 `bun.lock` 锁文件（之前仅有 package.json）
- `node_modules/` 目录首次出现

## 升级要点总结

**v5 的主题是"外部连接与可靠性"**。这个版本将项目从独立工具升级为可连接外部生态的平台：
1. **MCP 协议** — 最重要的架构扩展，让 Claude Code 可以连接任意 MCP 服务器
2. **自动压缩** — 首次引入对话上下文管理，为长对话提供保障
3. **配置管理** — 系统化的配置读写，提升可维护性
4. **重试机制** — 网络不稳定的兜底策略

相比 v4 的"安全与规划"，v5 更关注"连接更多工具"和"系统健壮性"。
