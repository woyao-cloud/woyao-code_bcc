## 新增功能

### 1. 权限管理（全新）
- **`src/services/permission/permissionManager.ts`** — 权限管理器
- 这是用户交互安全性的关键组件：工具执行前需要用户授权
- 支持白名单/黑名单模式，会话级别的权限控制

### 2. Plan Mode（全新）
- **`src/services/planMode.ts`** — 规划模式服务
- 引入"先规划后执行"的工作流：
  - EnterPlanModeTool：进入规划模式
  - ExitPlanModeTool：退出规划模式并提交执行
- 这是 AI 编程助手的核心交互范式之一

### 3. 新增 2 个工具（12→14）
| 新增工具 | 说明 |
|----------|------|
| EnterPlanModeTool | 进入规划模式，模型先输出计划，再执行代码变更 |
| ExitPlanModeTool | 退出规划模式，确认计划后执行 |

### 4. 新增测试
- `permissionManager.test.ts` — 权限管理测试
- `planMode.test.ts` — 规划模式测试

## 升级要点总结

**v4 的主题是"交互安全与规划工作流"**。从 v3 的工具扩展升级为具备：
1. **权限控制** — 首次引入用户授权机制，让用户对工具执行有控制权
2. **Plan-First 模式** — 模型先输出计划，用户确认后再执行，减少意外操作
3. **Token 追踪** — 描述中提及 token tracking，为后续的成本优化打下基础

这个版本标志着项目从"简单的 CLI 工具"向"具备安全规划的 AI 编程助手"的转变。权限管理和计划执行成为后续所有版本的基础设施。
