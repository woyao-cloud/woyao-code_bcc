# mini-v6 → mini-v7 升级分析

## 版本信息

| 维度 | mini-v6 | mini-v7 |
|------|---------|---------|
| 版本号 | 6.0.0 | 7.0.0 |
| 描述 | Plugin/Skill ecosystem | Memory system: SessionMemory, Memory Stores, Team Sync |
| 文件数 | 108 | 124 |
| 测试数 | 22 | 22 |

## 新增功能

### 1. 文档系统（全新）
- **`docs/`** — 首次引入项目文档
  - `architecture.md` — 整体架构说明
  - `README.md` — 文档入口
  - `modules/` — 各模块详细文档
    - cli.md, memory-system.md, permission-system.md, plugin-system.md, skill-system.md, tool-system.md

### 2. Memory 系统全面升级
v7 的重头戏，从 v3 引入的简单 `memoryStore.ts` 升级为完整的 Memory 体系：

| 文件 | 说明 |
|------|------|
| `memoryStore.ts` | 增强的记忆存储，支持 CRUD |
| `memoryStoresClient.ts` | **新增** — 统一的 Memory Store 客户端，聚合多个存储后端 |
| `sessionMemory.ts` | **新增** — 会话记忆管理，跟踪当前会话的上下文 |
| `teamMemorySync.ts` | **新增** — 团队记忆同步 |

架构分层：
```
memory/
├── memoryStore.ts          ← 存储层（基础的键值存储）
├── memoryStoresClient.ts   ← 客户端层（聚合多个 store）
├── sessionMemory.ts        ← 会话层（会话级别的记忆管理）
├── teamMemorySync.ts       ← 同步层（团队协作记忆同步）
```

### 3. Memory 命令（增强命令系统）
- **`src/commands/memoryCommands.ts`** — Memory 管理命令
- 支持查看、搜索、管理记忆内容

### 4. Memory 测试
| 新增测试 | 说明 |
|----------|------|
| memoryStore.test.ts | 记忆存储测试 |
| sessionMemory.test.ts | 会话记忆测试 |

### 5. 工具数量不变（15 个）
和 v6 一样，v7 也没有新增工具，重点是内部架构升级。

## 升级要点总结

**v7 的主题是"记忆体系"**。这是内部架构最深刻的版本之一：
1. **分层记忆架构** — 从单文件存储升级为四层架构（存储→客户端→会话→同步）
2. **会话记忆** — 首次支持跨轮次的上下文感知
3. **团队同步** — 为多 Agent 协作铺路
4. **文档体系** — 首次建立完整的模块文档
5. **零新工具** — 纯内部架构升级，用户界面不变

v7 为 v8 的多 Agent 协作提供了记忆基础。
