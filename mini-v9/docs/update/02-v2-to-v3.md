# mini-v2 → mini-v3 升级分析

## 版本信息

| 维度 | mini-v2 | mini-v3 |
|------|---------|---------|
| 版本号 | 2.0.0 | 3.0.0 |
| 描述 | 8 core tools | Agent tasks, patch tool, skills, memory |
| 文件数 | 73 | 82 |
| 测试数 | 14 | 16 |

## 新增功能

### 1. Memory 系统（全新）
- **`src/services/memory/memoryStore.ts`** — 记忆存储层，支持跨会话持久化
- 这是整个项目中首次引入记忆能力

### 2. Skill 系统（全新）
- **`src/services/skill/skillLoader.ts`** — Skill 加载器
- 支持从文件系统和配置中加载可复用的 skill（技能模板）

### 3. Task Store（全新）
- **`src/services/taskStore.ts`** — 任务存储服务
- 为后续的 TaskCreate/TaskList/TaskUpdate 工具提供持久化支持

### 4. 新增 4 个工具（8→12）
| 新增工具 | 说明 |
|----------|------|
| ApplyPatchTool | 应用补丁（比 FileEditTool 更智能的代码修改） |
| SkillTool | 调用 skill 技能 |
| TaskCreateTool | 创建任务 |
| TaskListTool | 列出任务 |
| TaskUpdateTool | 更新任务状态 |

### 5. 新增测试
- `applyPatch.test.ts` — 补丁应用功能测试
- `taskStore.test.ts` — 任务存储测试

## 升级要点总结

**v3 的主题是"扩展工具生态"**。从 v2 的纯执行骨架升级为一个支持**任务管理 + 技能调用 + 内存存储**的智能助手。关键架构决策：
- Memory 和 Skill 作为独立 service 层，与 API 层平级
- 工具数量从 8 个扩展到 12 个，引入补丁应用、任务管理、技能调用三类新场景
- 没有引入 UI 层，仍然是纯 CLI 交互
