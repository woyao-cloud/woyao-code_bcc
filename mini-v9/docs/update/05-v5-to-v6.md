# mini-v5 → mini-v6 升级分析

## 版本信息

| 维度 | mini-v5 | mini-v6 |
|------|---------|---------|
| 版本号 | 5.0.0 | 6.0.0 |
| 描述 | MCP, config, auto-compact, retry | Plugin/Skill ecosystem, marketplace, skill discovery & install |
| 文件数 | 98 | 108 |
| 测试数 | 22 | 22 |

## 新增功能

### 1. Plugin 系统（全新）
- **`src/plugins/`** — 完整的插件生态
  - `pluginLoader.ts` — 插件加载器（扫描本地目录加载插件）
  - `pluginInstaller.ts` — 插件安装器（从 marketplace 安装）
  - `marketplaceManager.ts` — Marketplace 管理器（浏览/搜索/安装）
  - `types.ts` — 插件类型定义
  - `index.ts` — 公开 API
- 支持从以下来源发现插件：
  - Built-in（内置插件）
  - 用户目录（~/.claude/plugins/）
  - 项目目录（.claude/plugins/）
  - Marketplace（远程插件市场）

### 2. Skill Store（增强）
- **`src/services/skill/skillStore.ts`** — Skill 存储层
- 从 v5 的纯 `skillLoader.ts` 升级为 Loader + Store 双层架构
- Skill 发现范围：built-in → ~/.claude/skills/ → .claude/skills/ → 插件来源

### 3. 命令系统（全新）
- **`src/commands/`** — 首次引入命令系统
  - `pluginCommands.ts` — 插件管理命令（list/install/uninstall/enable/disable）
  - `skillCommands.ts` — Skill 管理命令（list/info/run）
- 这是 CLI 交互范式的重大升级：从简单的问答模式扩展为支持丰富的子命令

### 4. 工具数量不变（15 个）
v6 没有新增工具，而是通过 Plugin 系统动态扩展工具能力。

### 5. 新增测试
| 新增测试 | 说明 |
|----------|------|
| marketplaceManager.test.ts | Marketplace 管理测试 |
| pluginLoader.test.ts | 插件加载测试 |

## 升级要点总结

**v6 的主题是"插件生态与命令系统"**。这是一个架构分水岭版本：
1. **Plugin 系统** — 首次引入动态扩展机制，工具不再局限于内置列表
2. **命令系统** — CLI 交互从纯自然语言升级为结构化命令模式
3. **Skill Store** — Skill 管理规范化，支持发现、安装、管理
4. **无新工具** — 这是一个"平台化"版本，重点在框架而非具体功能

v6 标志着项目从"单体工具"向"可扩展平台"的转型。
